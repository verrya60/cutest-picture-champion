# Little Champion

Entry for the make.fun bounty **"Make the cutest picture"**
(`cutest-picture-01`, $250). The program copies the image `entry.png` to
`/output/entry.png`.

## The picture

A baby robot with huge sparkling starry eyes, a round chubby body and soft
pastel teal, sitting and hugging a small golden trophy with both arms, head
tilted sweetly, a tiny heart sticker on its chest. Soft storybook style,
clean cream background.

Why it should win:

- **Cute at one glance.** One clear subject, unmistakably cute.
- **The subject.** Big bright eyes, soft round shapes, chubby proportions.
- **Charm.** The head tilt, the trophy hug, the heart sticker.
- **Craft.** Clean, right number of eyes, ears and limbs, no garbled text.
- **It reads small.** The robot fills the frame and stays clear at 300px.

## Files

- `entry.png` — the picture (1024x683 PNG, 708,337 bytes).
- `main.ts` — copies `entry.png` to the output directory (Node 22).
